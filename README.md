Лабораторна робота №3
Тема. Робота з великими мовними моделями через API. 
Завдання 1. Взаємодія з великою мовною моделлю Обрати будь-яку доступну велику мовну модель (наприклад, ChatGPT, Gemini, Claude або іншу) та виконати 5 різних типів запитів:
1. Пояснення — попросити пояснити певне поняття.
2. Генерація тексту — створити невеликий текст на задану тему.
3. Переклад — перекласти текст з однієї мови на іншу.
4. Узагальнення — скоротити та узагальнити запропонований текст.
5. Генерація списку — сформувати список за заданими критеріями.
Для кожного запиту зафіксувати:
• текст prompt;
• отриману відповідь;
• короткий аналіз результату.
Рекомендується використовувати одну предметну область, наприклад інформатику, програмування або штучний інтелект.
Завдання 2. Порівняння способів формування prompt
Для однієї обраної задачі створити два варіанти prompt:
1. Zero-shot prompt — сформулювати завдання без прикладів.
2. Few-shot prompt — перед виконанням основного завдання надати моделі 2–3 приклади бажаного результату.
Порівняти отримані відповіді та визначити:
• який результат є більш точним;
• який результат краще відповідає поставленому завданню;
• чи змінилася структура відповіді;
• чи допомогли приклади моделі краще виконати завдання.
Завдання 3. Удосконалення prompt
Отримати відповідь моделі на простий або недостатньо конкретний prompt.
Наприклад:
Розкажи про штучний інтелект.
Проаналізувати недоліки такого prompt та створити його вдосконалений варіант.
Під час вдосконалення можна додати:
• роль моделі;
• конкретну інструкцію;
• контекст;
• бажаний обсяг відповіді;
• формат відповіді;
• цільову аудиторію.
Порівняти результати виконання початкового та вдосконаленого prompt.
Завдання 4. Використання системної ролі
Дослідити вплив system role / системної інструкції на відповідь мовної моделі.
Для однієї задачі використати різні ролі, наприклад:
• викладач;
• програміст;
• науковець.
Порівняти отримані відповіді та зробити висновок про вплив ролі на стиль і зміст відповіді.

Встановлення та запуск:

Для встановлення необхідних бібліотек:
py -m pip install -r requirements.txt 
або
py -m pip install flask google-genai

Для коректної роботи апі ключа використовували бібліотеку os
Щоб апі ключ працював потрібно ввести:
$env:GEMINI_API_KEY="GEMINI_KEY"

Після цього запускаємо програму:
python app.py
